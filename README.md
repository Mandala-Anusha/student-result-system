\# Student Result Management System



A full-stack web application to manage and track student academic results with automated grade calculation.



\## What it does

\- Add student results with subject marks

\- Automatically calculates total, percentage, grade and pass/fail status

\- Search students by name or roll number

\- Delete student records

\- Real-time dashboard showing total students, passed, failed and average percentage



\## Tech Stack

\- \*\*Python\*\* - Core programming language

\- \*\*Flask\*\* - Backend REST API

\- \*\*SQLite\*\* - Database for storing student records

\- \*\*HTML, CSS, JavaScript\*\* - Frontend



\## Grade Calculation

| Percentage | Grade |

|---|---|

| 90 and above | A+ |

| 80 - 89 | A |

| 70 - 79 | B |

| 60 - 69 | C |

| 50 - 59 | D |

| Below 50 | F |



\## How to run

```bash

pip install flask flask-cors

python app.py

```

Open browser at http://127.0.0.1:5001



\## Features

\- REST API with Flask

\- SQLite database with CRUD operations

\- Automatic grade and pass/fail calculation

\- Search functionality

\- Clean responsive UI
